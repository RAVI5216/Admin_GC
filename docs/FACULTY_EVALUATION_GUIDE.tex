\noindent\textbf{Platform Summary:} GarbageGuardian is an IoT fleet monitoring and municipal waste management platform integrating live hardware telemetry, scikit-learn NLP incident triage, and field task dispatch across a modern React, Express, and AWS DynamoDB architecture.

\vspace{0.6em}

% --- Section 1: Quickstart ---
\section*{1. How to Run the Project}
An automated script inspects your laptop's software stack (Node.js, npm, Python 3, venv, AWS CLI), installs required packages, and starts all services concurrently.

\subsection*{Step 1: Open Terminal / Command Prompt in the Project Folder}
\begin{codebox}
# If using Git:
git clone https://github.com/RAVI5216/Admin_GC.git
cd Admin_GC

# If using the extracted Admin_GC_Source.zip archive:
cd Admin_GC
\end{codebox}

\subsection*{Step 2: Execute the Automated Launcher}
\begin{itemize}
    \item \textbf{On macOS / Linux:}
    \begin{codebox}
    ./scripts/run_for_faculty.sh
    \end{codebox}
    \item \textbf{On Windows (Command Prompt / PowerShell):}
    \begin{codebox}
    scripts\run_for_faculty.bat
    \end{codebox}
\end{itemize}

% --- Section 4: Key Features ---
\section*{4. Key Features to Test in the Web Portal}
\begin{enumerate}
    \item \textbf{Dashboard (\texttt{/})}: Overview fleet capacity gauge, active incident tally, and live sensor area charts.
    \item \textbf{Live GIS Map (\texttt{/map})}: Interactive Leaflet map with color-coded status halos (Normal, Warning, Overflow).
    \item \textbf{Smart Bins Fleet (\texttt{/bins})}: Multi-sensor diagnostics (ultrasonic distance, temperature, humidity, gas).
    \item \textbf{Citizen Reports \& AI Classifier (\texttt{/reports})}: NLP complaint triage with severity and department routing.
    \item \textbf{Task Dispatch (\texttt{/tasks})}: Real-time assignment and tracking of waste collection tasks for field crews.
    \item \textbf{Employer Roster (\texttt{/employers})}: Registry for sanitation personnel with automated Employee IDs.
\end{enumerate}
